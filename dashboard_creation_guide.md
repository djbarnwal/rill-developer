This guide will walk you through the process of creating and customizing dashboards in Rill, including how to use the web interface, add visualizations, and configure dashboard settings. We'll also cover information on themes and embedding options.

## Creating a New Dashboard

To create a new dashboard in Rill:

1. Log in to your Rill account.
2. Navigate to the Dashboards section.
3. Click on the "New Dashboard" button.
4. Enter a name for your dashboard and click "Create."

## Adding Visualizations

To add visualizations to your dashboard:

1. Click on the "Add Visualization" button.
2. Choose the type of visualization you want to add (e.g., chart, table, metric).
3. Configure the visualization settings, including data source and display options.
4. Click "Save" to add the visualization to your dashboard.

You can rearrange visualizations by dragging and dropping them on the dashboard canvas.

## Configuring Dashboard Settings

To configure your dashboard settings:

1. Click on the "Settings" icon in the dashboard toolbar.
2. Adjust the following options as needed:
   - Dashboard name and description
   - Time range settings
   - Refresh rate
   - Access permissions
3. Click "Save" to apply your changes.

## Customizing Dashboard Themes

Rill offers customizable themes for your dashboards. To apply or customize a theme:

1. Click on the "Theme" option in the dashboard toolbar.
2. Choose from available preset themes or click "Customize" to create your own.
3. If customizing, you can adjust:
   - Color scheme
   - Font styles
   - Background colors
   - Chart styles
4. Preview your changes in real-time.
5. Click "Apply" to save your theme settings.

## Embedding Options

Rill allows you to embed your dashboards in external websites or applications. To embed a dashboard:

1. Open the dashboard you want to embed.
2. Click on the "Share" button in the dashboard toolbar.
3. Select the "Embed" tab.
4. Choose your embedding options:
   - iframe embed
   - JavaScript embed
   - Public link (if applicable)
5. Copy the provided code or link and use it in your desired location.

Remember to consider security settings when embedding dashboards, especially if they contain sensitive information.

For more advanced customization options and API integration, please refer to our API documentation.
